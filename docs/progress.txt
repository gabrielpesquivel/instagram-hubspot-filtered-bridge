KEY TECHNICAL NOTES:
--------------------
- Profile fetch uses graph.facebook.com/v21.0/{IGSID} (not graph.instagram.com)
- Field mapping: API returns is_verified_user, code maps to is_verified
- Falls back to "name" field if "username" not available
- Send message uses /{INSTAGRAM_PAGE_ID}/messages (not /me/messages)
- HubSpot outbound webhook type: OUTGOING_CHANNEL_MESSAGE_CREATED
- Recipient IGSID at: payload.message.recipients[0].deliveryIdentifier.value
- Message text at: payload.message.text
- HubSpot channel uses CHANNEL_SPECIFIC_OPAQUE_ID (not HS_EMAIL_ADDRESS)
- Channel account ID fetched from API on first message, then cached in KV
- HubSpot 409 on channel connect = already exists, treated as success
- Instagram webhook signed by Instagram App (<INSTAGRAM_APP_ID>), NOT Facebook App
- HubSpot webhook verified via X-HubSpot-Signature-v2 (SHA-256 of clientSecret + method + url + body)

SECURITY:
---------
- Instagram webhook: HMAC-SHA256 signature verification (enforced, rejects invalid)
- HubSpot webhook: X-HubSpot-Signature-v2 verification (enforced, rejects invalid)
- Both endpoints return 401 Unauthorized on signature mismatch
